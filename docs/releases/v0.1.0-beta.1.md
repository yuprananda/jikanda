# Jikanda v0.1.0-beta.1

The first Windows beta of Jikanda: a calm, local-first desktop focus companion.
Built with Rust and Slint. By Yu Prananda. GPL-3.0-only.

## Download and install

- **Windows 11 x64:** download `Jikanda-0.1.0-beta.1-windows-x64.zip`.
- Extract the entire ZIP, open its folder, and run `jikanda.exe`.
- Optional Start menu shortcut: run the included `install-windows.ps1` from PowerShell.
- [Installation guide](https://github.com/yuprananda/jikanda/blob/main/docs/installation.md)
  / [Bahasa Indonesia](https://github.com/yuprananda/jikanda/blob/main/docs/installation-id.md).
- The beta is unsigned. Verify the source and SHA-256 in `SHA256SUMS.txt`.
- The separate source ZIP includes the exact application sources, assets, build
  scripts, dependency notices, and vendored crates for offline builds.

## Included

- Pomodoro 25/5 minutes, Deep Focus 50 minutes, and Flow count-up.
- Accurate pause/resume, explicit finish/save/discard, and sleep-gap pausing.
- Session names/checklists, local history, correction/deletion, daily/weekly totals.
- Compact draggable mini timer with Windows topmost/opacity controls.
- Monochrome light/dark UI, English and Bahasa Indonesia.
- Desktop notifications and three original short alarm sounds, with optional mute.
- One-session offline PNG cards, optional name/completed tasks, Story/Feed formats.
- Mascot icon from the maintainer's brand guide in executable/window/shortcut.

Recorded time is session time, not objectively verified productivity. No accounts,
analytics, surveillance, automatic uploads, or cloud backend are included.

## Beta limitations

- Windows 11 x64 is the tested desktop. Windows 10/ARM64 are not verified.
- No Linux binary in this release. Linux source/CI checks do not validate X11/Wayland
  runtime behavior; topmost/positioning depend on the compositor and opacity is unavailable.
- Additional hardware, scaling, multi-monitor, physical sleep/hibernate, and assistive
  technology testing is welcome. Native automated snapshots do not replace those checks.
- Active sessions are not restored after a crash/restart. Back up `state.json` before beta testing.
- Clicking a Windows toast does not currently activate the main Jikanda window.
- Raster brand icons are used for this beta; vector masters remain future work.

Settings/history remain in `%LOCALAPPDATA%/Jikanda` when updating or removing the
application files. Close Jikanda before replacing its executable.

Report bugs with app version, OS, scaling, steps, and expected behavior. Remove
personal session names, tasks, and paths before sharing screenshots or logs.
