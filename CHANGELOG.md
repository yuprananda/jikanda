# Changelog

## 0.1.0-beta.1 - 2026-11-09

First Windows beta of Jikanda, by Yu Prananda.

- Pomodoro 25/5 minutes with four focus segments, Deep Focus 50 minutes, Flow count-up.
- Monotonic time accounting, pause/resume, explicit completion/interruption, sleep-gap pause.
- Named sessions, synchronized session checklists, local history and daily/weekly summaries.
- Compact mini timer, Windows topmost/opacity, monochrome light/dark UI, English/Indonesian.
- Three original licensed alarm signals, optional mute/preview and desktop notifications.
- One-session PNG cards in Story/Feed formats, optional display name and completed tasks.
- Refined responsive text and dialogs at supported window sizes.
- Maintainer-provided mascot icon embedded in executable/window/shortcut; version metadata.
- Windows installation/update/uninstall guides, screenshot examples and beta limitations.
- GPL-3.0-only, retained third-party notices, complete vendored corresponding-source ZIP.

Windows 11 x64 is the tested desktop. No Linux binary in this beta; Linux runtime,
more physical hardware/scaling/suspend and accessibility testing remain open.
The beta is unsigned. See docs/release-readiness.md and docs/releases/v0.1.0-beta.1.md.

Prototype development history is retained in docs/history/changelog-prototype.md.
